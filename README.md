# Portfólio Rafael Dias

Site estático publicado no GitHub Pages.

- `assets/js/projetos.js`: lista de projetos e contato (edite aqui).
- `assets/js/imagens.js`: manifesto gerado automaticamente.
- `tools/otimizar-imagens.sh`: gera as versões web a partir da pasta de originais e o `tools/imagens.tsv`.
- `tools/gerar-manifesto.sh`: transforma o `imagens.tsv` em `assets/js/imagens.js`.
